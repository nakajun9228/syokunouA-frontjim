1. 社員情報の入力

評価対象者を入力してください。入力内容と評価結果は、このPCのブラウザ内だけに保存されます。

2. 基準となるLevelを選択

通常評価では、選んだLevelを中心に、1つ前のLevel → 選んだLevel → 1つ先のLevelの昇順で評価します。Level1では1→2、Level7では6→7となります。

4. 評価結果

評価したLevelを一覧で表示します。知識・技術は別々に判定・得点化しています。

S＝4点A＝3点B＝2点C＝0点－＝2点

任意のLevelを追加評価

標準フロー：1つ前のLevel → 選択Level → 1つ先のLevelの昇順。3Level評価で一番高いLevelが最高得点の場合は、次のLevelを追加評価します。上位Levelで得点が下がった時点で現在のLevelを確定します。Level1は1→2、Level7は6→7です。各職能要件は「知識3要素」「技術3要素」を別々に判定します。
